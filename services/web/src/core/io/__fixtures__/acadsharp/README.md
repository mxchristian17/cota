# Muestras de ACadSharp

Dibujos de muestra del proyecto [ACadSharp](https://github.com/DomCR/ACadSharp) (carpeta `samples`, commit
25b5348), bajo su licencia MIT (`LICENSE` en esta carpeta). Son el mismo dibujo base, con unos
40 tipos de entidad, guardado en distintas versiones: los usa `cadSamples.test.ts` para validar el lector de DWG y el
importador DXF.

- `sample_AC1032.dwg` — DWG 2018
- `sample_AC1015.dwg` — DWG 2000
- `sample_AC1032_binary.dxf` — DXF binario 2018
- `sample_AC1009_ascii.dxf` — DXF R12
